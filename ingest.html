这一页把边界说清楚：哪些事浏览器自己能做完，哪些必须交给网关或后端。四页共用同一套前端数据引擎，不发任何请求。

浏览器做不了的事

不能直连 PLC、读串口、订阅 MQTT、写数据库，也绕不过跨域限制。这些只能由网关或后端完成，前端只接收归一后的快照。

设备状态语义

STATE MAPPING
状态判定依据画面处理
运行状态字运行位 = 1 且节拍正常青色灯带常亮，地面光斑呼吸
待机上电但未启动 / 换型 / 缺料灰色，降低亮度，不计产出
预警连续 3 个周期越预警阈值琥珀色，光斑脉冲，进告警表
故障停机位 = 1 或安全联锁触发赤色，光斑扩散，KPI 高亮
颜色只表达状态，不表达“好看”。同一状态在三维、列表、图表、告警表里必须是同一个色值。

归一：单位

UNIT

温度统一 ℃，振动统一 mm/s，节拍统一 秒，功率统一 kW。原始寄存器里的 0.1℃ / rpm 要在数据源一侧换算掉——样机里由 plant.js 直接产出工程单位，将来有网关时在网关做。

理由：一旦让前端换算，同一台设备在不同页面会出现两个数。

归一：时区

TIME

整包带时区偏移，ts 统一成 UTC+8 的 ISO 字符串（样机里由 plant.js 生成），前端只负责格式化。跨班统计以 08:00 / 20:00 为界。

理由：夜班跨零点，用“今天 0 点”切分会把一班拆成两半。

归一：断流

STALE

超过 3 个采集周期没有新值，点位质量位记为 stale，画面上保留最后有效值并打“数据陈旧”标记，绝不用 0 填充。

理由：0 会被当成真实读数，直接拉低 OEE 且没人发现。

交付清单

ACCEPTANCE
  • 数据：12 台设备状态、指标、产出与告警同源，切换页面数值连续。
  • 视觉：状态色四态一致；青色只做点缀；数字用等宽字体不跳动。
  • 交互：三维点选、设备切换、告警筛选与确认全链路可用。
  • 性能：原生 Canvas 与 SVG，无 WebGL 依赖，首屏不加载第三方库。
  • 断流：暂停采集即打“数据陈旧”，画面保留最后有效值。
  • 适配：手机单列、平板双列，主要数值在 360px 宽下仍可读。
